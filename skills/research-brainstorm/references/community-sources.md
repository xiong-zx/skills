# Community inspiration and adaptation

Primary skill files and the listed deeper references were inspected on 2026-10-27. The procedures here are selectively adapted and independently worded. These links acknowledge design sources; users do not need to install or load these repositories to use research-brainstorm. A published workflow is inspiration, not evidence that its generated topics are scientifically valid.

| Source | Useful ideas adopted | Requirements not carried over |
| --- | --- | --- |
| [Research-Equality scientific-brainstorming](https://github.com/Research-Equality/RE-idea-generation/blob/main/skills/scientific-brainstorming/SKILL.md) | Conversational exploration, adapt the thinking move to the blockage, connect ideas before evaluating them | Mandatory final shortlist and output headings; automatic use of unavailable follow-on skills |
| [K-Dense scientific-brainstorming](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/scientific-brainstorming/SKILL.md) | Distinguish generation, evidence and validation; initial independent generation, relevant evidence, then reopen; preserve disagreement | Group-workshop machinery, fixed scoring/registers, scripts or domain-specific review checklists for unrelated research |
| [K-Dense hypothesis-generation](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/hypothesis-generation/SKILL.md) | Separate observation, candidate explanation, prediction and evidence; compare rivals using distinguishing predictions | A mandatory biomedical or preregistration-shaped workflow; requiring an experiment before every theory question |
| [Microsoft ResearchStudio scoop-check](https://github.com/microsoft/ResearchStudio/blob/main/ResearchStudio-Idea/skills/scoop_check/SKILL.md) | Separate the problem from the claimed contribution, search different formulations, inspect close prior work before describing the difference | Axis-count novelty levels, no-hit novelty inference, never-ask rules, fixed host tools and per-step log files |
| [UCL-ERL research-idea-rubric](https://github.com/UCL-ERL/skills/blob/main/skills/ideation/research-idea-rubric/SKILL.md) | Resource constraints, strong comparisons and a cheap falsification/feasibility check | Robotics criteria, numerical publication forecasts and required scorecards |
| [EvoSkills research-ideation](https://github.com/EvoScientist/EvoSkills/blob/main/skills/research-ideation/SKILL.md), especially its refinement and proposal sections | Find the weakest link, simplify or replace the mechanism, revisit after evidence, expand a requested candidate into a field-appropriate plan | Mandatory 30–50-paper searches, fixed personas/tracks/rounds, Elo ranking, automatic memory files and experiment execution; blanket claims that a failure case ensures publication |
| [zhonxia research-ideation](https://github.com/zhonxia/research-ideation/blob/main/SKILL.md), [generation methods](https://github.com/zhonxia/research-ideation/blob/main/references/idea-generation-methods.md), [evaluation guide](https://github.com/zhonxia/research-ideation/blob/main/references/evaluation-guide.md) | Assumption/boundary questions, contradiction alignment, counterexamples, measurement and regime questions, explicit cross-field transfer, check matched to contribution type | BRB-specific defaults, mandatory efficacy/algorithm-improvement route, weighted random methods, beginner-only/no-terminology rules, new registries and per-idea directories |

The confirmed taste, support for mechanism-only contributions, resource exclusions, web-first retrieval, writing rules and no-duplicate-document policy come from this user's instructions and installed skills. They are not claims made by all of the sources.

Writing-research, explain-project, explain-paper and review-manuscript provide the local language baseline described in [communication](communication.md). Existing communication-source acknowledgments were preserved there. The shared skill contains no copied upstream scripts, services or package dependencies.

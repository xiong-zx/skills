# Explain Project

帮助用户恢复上下文、理解当前最重要的变化并作出判断。用户不需要记住旧长回复；详细研究可以充分展开，汇报应经过筛选。

## 按本次问题读取

先读 [共同汇报方法](references/report.md)，再按需要选择：

- [理论探索进展](references/theory-progress.md)：解释关键假设、公式、结果及证明状态。
- [长程研究与探索](references/long-horizon-research.md)：判断研究路线的价值、偏离与下一步取舍。
- [边界明确的任务与执行](references/task-progress.md)：说明实际完成、验证和交付。

不要为填满模板加载所有场景。一般先给简短地图，再展开用户关注的部分；用户明确要详解时提供所需深度。

## 范围

以最新用户决定和当前证据为准，区分目标改变、方法调整和新发现的限制。沿用项目现有记录与记号，具体汇报规则集中在共同方法中。

本 skill 用于解释和对齐。说明进展不自动授权新研究、审查、派遣、跨会话消息、文稿修改或改变目标；已有明确授权内的工作不必重复申请。

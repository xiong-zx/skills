# 长程研究与探索

先遵循 [共同汇报方法](report.md)。本场景帮助用户判断研究方向是否仍值得推进，具体执行由原有授权决定。

## 把局部进展放回目标

内部对齐总目标、本轮要解决的不确定性、当前结果三者。给用户只展示本次需要的关系：这个结果帮助回答了什么，还留下哪个关键困难。背景可以广泛探索，汇报不逐条展开所有路线。

区分正向结果、反例、已知机制和辅助结论。正确的特例未必代表一般问题；更长的证明、更多参数或更小常数只有改变重要判断时才值得突出。其他 agent 的结论保留来源和审查范围，不把汇总当成独立验证。

## 识别偏离与选择

当新限制移除了原问题的困难、辅助问题占据主要工作，或下一步价值取决于用户偏好时，简短指出偏离及影响。分别判断“能否做成”和“做成是否值得”；不要因一个问题容易推导就自动延伸。

给出推荐的下一项检验及其可能改变的判断。只有涉及目标、重要模型限制、资源或优先级的选择才需要用户决定；常规证明路线在已批准范围内继续。未经认可的建议不能写成已选定方向。

多会话工作复用现有记录，注明每个问题的负责人；除有明确目的的独立审查外，不重复推导已完成或仍有人负责的问题。用户无需从多个会话自行拼出项目状态。

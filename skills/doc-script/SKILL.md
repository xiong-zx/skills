# Talk Script

Write what the speaker can actually say, in connected spoken language. Adapt to the audience, occasion, speaking language, time and author's voice. Preserve the supplied science, current slide order and author edits; oral clarity does not authorize a stronger claim or a deck redesign.

## Read for the current work

- Always read [spoken language and flow](references/spoken-language-and-flow.md).
- For equations, proofs or figures, read [technical explanation](references/technical-explanation.md).
- For timing, shortening, revision or Presenter Notes, read [timing and delivery](references/timing-and-delivery.md). Notes synchronization requires authorization to edit the deck and the applicable doc-slides technical workflow.
- [Sources and limits](references/sources.md) records the university guidance and its adaptations; no external service or new literature search is needed for routine script writing.

## Workflow

1. Locate the existing active script and current saved slides/outline, including author comments, hidden backups and reveal order where available. Recover audience, purpose, duration, in-slot Q&A, speaking language and preferred delivery style. Do not infer the talk language from the language of this chat. Ask only material unknowns; a provisional draft can proceed with explicit assumptions.
2. Identify privately what the audience should understand on each page, how it connects to what came before and why the next point follows. Respect the approved order. Flag an actual gap rather than inventing a causal bridge, missing result or application.
3. Draft complete spoken passages with natural transitions within and between slides. Use direct verbs, manageable breath groups and contractions where natural. Guide attention to the important part of mathematics or a figure; do not merely read bullets or symbols. Keep essential assumptions, comparisons and uncertainty audible.
4. Separate read-aloud prose from brief delivery cues and non-spoken technical notes. Allocate a realistic word/character and time budget with pauses, attention to visuals and an optional shorter route; label estimates as rehearsal targets.
5. Do one text-based speakability pass: awkward wording, unclear references, new terms, broken transitions, repeated slide-reading, claim fidelity and timing. Update one existing script in place when file editing is requested. Synchronize the same current script to Presenter Notes only when authorized, with readback verification.

Deliver the script itself, with only useful timing/cue information and unresolved issues. Do not substitute a checklist or teaching report for the requested prose. A text check or synthetic voice is not evidence that the author rehearsed the talk.

This skill owns oral delivery wording. Reuse writing-research for terminology, meaning and evidence preservation, while this skill overrides its written register. Use doc-slides for authorized changes to slides, layout, equations or notes plumbing; skill creation alone does not authorize editing a supplied deck.
